# حکمنامه — برنامه مهندسی Stage / Work / Task

> نسخه r1 | ۲۰۲۶/۱۱/۱۹ | مبنا: سورس GitHub v0.1، مصوبات بازیابی‌شده از گفتگوهای پروژه. لینک خصوصی سند مادر قابل بازبینی مستقیم نبود؛ این سند «diff قطعی با آخرین ویرایش صاحبکار» نیست.

## وضعیت و حدود برنامه

- در GitHub فعلی: ۴۱ فایل bootstrap؛ موتور پایه C#، حساب مهمان، اتاق حافظه‌ای، ربات heuristic، Unity IMGUI و LAN نمونه وجود دارد.
- فهرست زیر **Backlog** است؛ ثبت آن به معنی پیاده‌سازی نرم‌افزاری نیست.
- Runtime اصلی، اقتصاد، رنک، UI نهایی، AI-01 و مقیاس هزاران نفر هنوز آماده تولید نیستند.
- تغییرات محرز در محصول از گفتگوهای پروژه اخذ شده و باید با متن آخرین سند مادر صاحبکار نهایی تطبیق شوند.

## طبقه‌بندی تصمیم‌ها

- **قطعی** — ۴ زمین: آکادمی، آزاد، رنک، جام اسپانسر (سیاست محصول ثبت‌شده)
- **قطعی** — ورود آزاد و رنک رایگان و نامحدود (اقتصاد و دسترسی)
- **قطعی** — بازی با بات فقط XP؛ منبع تولید سکه نیست (اقتصاد)
- **قطعی** — رنک Solo و Duo، ترجیح مسابقه هم‌نوع (همتاسازی)
- **قطعی** — ۶ لیگ و فصل سه‌ماهه تقویمی (لیگ و فصل)
- **قطعی** — VIP حذف و هیچ خریدی مزیت رقابتی ندارد (اقتصاد)
- **قطعی** — روی میز چت آزاد ممنوع؛ پیام آماده تحت کنترل (Trust & Safety)
- **قطعی** — ترک بازیکن: ربات جایگزین + پیامد متناسب (مدیریت مسابقه)
- **قطعی** — تاج شکسته و تالار پادشاهان فراموش‌شده (روایت و حفظ بازیکن)
- **قطعی** — لابی الهام‌گرفته از چیدمان Mobile Legends با هویت مستقل (Unity UI)
- **قطعی** — داشبورد مجزا و شیشه‌ای روی لابی؛ پروفایل/Level/آواتار/اعتبار مستقل (Unity UI)
- **قطعی** — حکم آرنا در فاز دوم، جدا از کلاسیک (Rulesets)
- **قطعی** — هوش کیفیت بازی نباید با اطلاعات مخفی یا در مسابقه زنده تقلب کند (AI-01)
- **نیازمند تأیید** — گردش حاکم و فرمول دقیق کُت/امتیاز در همه نوع بازی (Ruleset v1)
- **نیازمند تأیید** — دقیق‌ترین سیاست اعتراض و تنبیه قطع غیرعمدی (Trust & Safety)
- **نیازمند تأیید** — ثبت تاریخ و متن نهایی نسخه ویرایش‌شده صاحبکار (Source-of-truth)
- **پیشنهاد فنی** — برنامه فنی .NET 10 + PostgreSQL + C# Core + Unity (Architecture)
