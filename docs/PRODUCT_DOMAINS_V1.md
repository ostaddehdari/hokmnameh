## جداسازی قطعی Arena

Arena زمین اصلی فاز اول نیست و `hokm-arena-v1` یک Ruleset مستقل در فاز دوم است. وتوی حکم، شکستن خال، واگذاری سرنوبت و تفویض حکم تحت هیچ شرایطی وارد `iranian-hokm-classic-v1`، آزاد یا رنک کلاسیک نمی‌شوند. افزودن هر قابلیت Arena به Classic نیازمند Change Request جدید است و باید fail-closed رد شود.

## اقتصاد رقابت سالم

- ورود آزاد و رنک همیشه صفر سکه و تعداد بازی هر دو نامحدود است.
- VIP، خرید MMR/ستاره، کارت قوی‌تر یا هر مزیت رقابتی پولی ممنوع است.
- سکه فقط برای پاداش‌ها و اقلام غیررقابتی/تزئینی استفاده می‌شود.
- آکادمی منبع سکه نیست؛ فقط XP می‌دهد.
- تورنمنت اسپانسری استخر پول بازیکنان یا شرط‌بندی ندارد؛ جایزه از اسپانسر و طبق قوانین منتشرشده تأمین می‌شود.

## مرز تغییر

این قرارداد Scope را تثبیت می‌کند و جایگزین تسک‌های پیاده‌سازی Matchmaking، Tournament یا Economy نیست. تغییر شناسه زمین، مجوز، هزینه ورود، محدودیت بازی، اثر رتبه یا مرز Arena باید با Change Request و نسخه جدید قرارداد انجام شود.
