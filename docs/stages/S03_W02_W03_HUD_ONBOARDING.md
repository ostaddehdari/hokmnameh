# S03-W02-T03 / S03-W03-T01 — نوار بازیکن و شروع آکادمی

- چهار کامپوننت مستقل نام، آواتار، Level و اعتبار در `PlayerHeader` با داده‌های API مربوط به خود نمایش داده می‌شوند. چیدمان `ProfileHudLayout` مستقل از Unity، برای RTL و LTR در عرض‌های ۲۸۰، ۳۲۰، ۵۰۴ و ۱۲۸۰ آزموده می‌شود.
- ورود به صفحهٔ آنلاین مهمان را خودکار ایجاد می‌کند؛ نام و آواتار قبل از ساخت میز تمرین ذخیره می‌شوند. شکست ذخیرهٔ پروفایل، شروع تمرین را متوقف می‌کند. بازی آفلاین به‌عنوان حالت محلی بدون XP سرور باقی می‌ماند.
- پیش‌نمایش آواتارهای موجود در سورس، طرح‌های سادهٔ تولیدشده در کد هستند. هیچ فایل تصویری از کتابخانهٔ شخصی مالک به مخزن عمومی منتقل نشده است.
- محدودیت پذیرش: اجرای Unity/اندروید و بازبینی فونت و شکل‌دهی متن فارسی، RTL دیداری، ناحیهٔ امن صفحه و دسترسی‌پذیری روی دستگاه هنوز لازم است؛ این آزمون‌ها از CI سرور استنتاج نمی‌شوند.
